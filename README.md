**Info-Motion** este o platformă educațională interactivă creată pentru elevii de liceu (profil Mate-Info) care doresc să înțeleagă algoritmii fundamentali prin vizualizare și interactivitate.

🔗 **Link Live:** [Info-Motion.vercel.app](https://Info-Motion.vercel.app)

---

## 💡 Argumentare
Proiectul a apărut din nevoia de a transforma explicațiile teoretice rigide în experiențe vizuale. Deși există resurse precum PBInfo, **Info-Motion** aduce un plus de claritate prin animații pas-cu-pas și un limbaj adaptat nivelului elevilor.

## ✨ Funcționalități Principale

- 📚 **Lecții Interactive:** Teorie explicată simplu, însoțită de animații care ilustrează funcționarea algoritmilor în timp real.
- 🎮 **Gamification:** Sistem de punctaj (XP) și clasament (Leaderboard) pentru a stimula competitivitatea.
- 🧩 **Quiz-uri:** Verificarea cunoștințelor la finalul fiecărei lecții pentru fixarea conceptelor.
- 🏆 **Problema Zilei:** Integrare cu API-ul Codeforces pentru provocări zilnice cu bonusuri de puncte.
- 🌙 **Dark Mode:** Interfață optimizată pentru sesiunile lungi de studiu.
- 🛠️ **Admin Panel:** Panou complet pentru gestionarea conținutului (CRUD pe lecții).

## 🛠️ Tehnologii Folosite

### Frontend
- **React.js** - Biblioteca principală pentru UI.
- **Vite** - Build tool pentru performanță maximă.
- **CSS Flexbox/Grid** - Pentru o interfață responsivă (Mobile Friendly).

### Backend & Data
- **Firebase** (BaaS) - Autentificare, bază de date (Firestore) și stocare.
- **Codeforces API** - Pentru preluarea și verificarea problemelor de concurs.
